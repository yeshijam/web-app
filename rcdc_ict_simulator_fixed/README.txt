RCDC ICT Kit Virtual Manufacturing & 3D Assembly Simulator

HOW TO USE
1. Keep the complete folder structure unchanged.
2. Deploy this folder as the project root on Vercel, or open index.html through a local web server.
3. Do not upload only index.html; the css/ and js/ folders are required.

SOURCE PRESERVATION
The HTML markup, CSS rules, and JavaScript application code were extracted from the supplied original HTML. JavaScript was divided only at its existing numbered section comments (1–9). No application logic was rewritten.

External libraries (Tailwind CSS, Three.js and OrbitControls) are still loaded from their original CDN URLs.
